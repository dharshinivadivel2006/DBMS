Agricultural Crop Monitoring System

Abstract
The Agricultural Crop Monitoring System is a DBMS-based project designed to store and manage agricultural information. It maintains farmer, crop, soil, weather, and irrigation details in a centralized database.

Problem Statement
Managing agricultural information manually can lead to data redundancy, errors, and difficulties in retrieving records. This project provides an organized database system to manage agricultural data efficiently.

Objectives
- To maintain farmer details.
- To store crop information.
- To manage soil details.
- To record weather conditions.
- To maintain irrigation information.
- To improve data accuracy and consistency.

Technologies Used
- Database: MySQL
- Language: SQL
- Domain: Database Management System (DBMS)

Database Tables
1. Farmer
2. Crop
3. Soil
4. Weather
5. Irrigation

Modules
- Farmer Details Management
- Crop Details Management
- Soil Information Management
- Weather Monitoring
- Irrigation Management
- Crop Monitoring Reports

DBMS Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- PRIMARY KEY
- FOREIGN KEY
- JOIN

Advantages
- Reduces data redundancy.
- Improves data accuracy.
- Makes data retrieval easier.
- Maintains centralized agricultural records.
- Supports better agricultural decision-making.

Conclusion
The Agricultural Crop Monitoring System provides an organized way to store and manage agricultural data using MySQL. It helps improve data management and supports efficient agricultural planning.
